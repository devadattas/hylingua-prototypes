# HyLingua student app prototype

Clickable mock-data prototype of the HyLingua student app, served with GitHub Pages at https://devadattas.github.io/hylingua-prototypes/

It is a single HTML file with no build step and no dependencies beyond Google Fonts. Append `?theme=light` or `?theme=dark` to force a theme, and use the hash in the address bar to return to a screen.

The source of truth lives in the HyLingua repository under `prototypes/student-app`; this repository only mirrors it for preview.
